# 可选：让微信接收简报

本机阅读不需要微信。以下只连接你自己的PushPlus账号，不使用作者的绑定或入口，不群发、不购买或续费。

## 向导入口

正式安装后双击`wechat.cmd`。第一次安装时，也可以在终端运行`deploy.cmd install --wechat`。

## 本人完成的账号步骤

1. 在[PushPlus官网](https://www.pushplus.plus/)注册或登录，按当前平台要求完成实名。
2. 关注官方“pushplus 推送加”服务号，作为ClawBot明确拒收后的备用。
3. 打开[开发设置](https://www.pushplus.plus/uc-dev.html)，开启开放接口；如启用安全IP白名单，填写自己电脑实际出口。向导会显示一次检测结果；VPN/代理切换可能使不同目标看到不同出口，需以实际接口检查为准，不要关闭白名单来绕过。
4. 取得自己的用户token和SecretKey。已有可用密钥可以直接使用，无需为了本项目更换。
5. 在[渠道配置](https://www.pushplus.plus/uc-channel.html)选择微信ClawBot，用本人微信扫码，并主动发一条消息。
6. 只在本机向导的隐藏输入里填token和SecretKey，不发到GitHub Issue、聊天、命令行参数或截图。

没有这些账号动作的开放替代接口，因此需要你本人处理。验证码、扫码、实名和新建密钥不能由开源代码替你完成。

## 程序随后自动完成

- Windows当前用户DPAPI加密保存凭据。
- 核对实名、ClawBot绑定和主动对话状态。
- 必要时下载并核验Cloudflare官方连接组件。
- 启动私人阅读网关，等待临时通道注册完成。
- 在你的PushPlus账号创建或复用本应用自己的固定文档，保持仅本人登录可访问；通道变化时静默更新同一文档。
- 得到同意后发送一条测试，请你确认手机能看到且能打开入口，再启用微信提醒。

中途取消或出现错误，仍恢复原有本机阅读状态。未确认的微信连接不会被当作已经完成；凭据和进度保留在本机，稍后重跑向导即可。

## 实际使用

每天09:00、21:00优先ClawBot，只发当天五篇简介、提醒和固定入口；详细阅读在网页进行。固定文档的地址不变，首次或会话过期时可能需要登录你自己的PushPlus。

ClawBot官方要求初次主动对话，并在每10次下发或每24小时后再次主动对话。表单提交、网页点击不能冒充这次微信主动消息。明确失败才用已有服务号备用，发送结果未知不跨渠道盲目重发。

免费临时隧道的底层地址可能改变，电脑也必须开机联网。文档固定入口用于转向最新地址，不代表隧道有长期可用性保证。希望全天在线需要另外部署常在线主机及稳定入口，这不在当前一键Windows流程中，也不会自动产生费用。

## 平台能力与费用

默认不用会员表单回调或收费短信/语音。ClawBot、文档开放接口、调用额度与实名要求以该账号当时平台页面为准。遇到账号不开放的功能时，停止该可选步骤，继续本机阅读；本项目不会自动购买会员来解决限制。

接口安全IP变更需要本人核对并更新平台设置。本项目不会定时放开白名单或扩大允许地址范围。
