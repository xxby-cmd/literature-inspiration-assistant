# 从零安装与部署

## 先确定使用方式

推荐先跑**本机阅读**：只需要Windows 10/11 x64、网络和有可用Codex额度的ChatGPT账号。微信可以以后再接，不影响主题调研、阅读与书架。

想先看看界面而不登录，运行`先体验.cmd`。演示内容明确标注，不能当作真实研究引用；之后运行`一键部署.cmd`进入正式实例。

## 下载与运行

1. 从[本仓库](https://github.com/xxby-cmd/literature-inspiration-assistant)选择Code → Download ZIP。
2. 解压到有写入权限的普通文件夹，例如`D:\文献启发助手`。支持空格和中文路径。
3. 双击`一键部署.cmd`。如果Windows因文件来自互联网要求你决定是否运行，请核对仓库来源后由你本人处理提示；脚本不会修改系统安全设置。
4. 等待依赖安装、构建和本地数据库准备。首次安装依赖需要网络；不要在这时移动源码目录。
5. 按提示完成官方ChatGPT登录，然后输入自己的关注方向和学习基础。回车可采用示例默认值。
6. 浏览器出现阅读器后可以开始使用。首次真实日报和粗读需要生成；生成中可离开页面，结果会保存。

正常路径不需要手动编辑JSON、创建数据库、配置Cloudflare账号、GitHub登录或安装Sites插件。

## 自动安装的范围

- Python：优先使用已安装且版本合适的Python；否则通过`winget`安装用户范围的官方Python 3.13。
- Node：复用合适版本；不合适时下载官方LTS便携包，先核对官方SHA256，再解压到应用自己的工具目录，不替换系统Node。
- Codex：使用官方`@openai/codex`分发；新安装放应用工具目录。
- 网页：按`package-lock.json`安装依赖、构建、创建本地数据库。
- 启动：检查本实例，空闲端口冲突时自动换一组；通过实例身份检查确认后端属于当前数据目录。

脚本不会配置或购买云主机。默认后端只监听本机；微信手机访问另见[微信接入](微信接入.md)。

## 必须本人完成的步骤

**ChatGPT登录**不能由作者代办。应用有独立Codex配置目录，因此即使桌面Codex已登录，首次仍可能要求再登录一次。它不会复制你的桌面认证文件，也不会退出或改变桌面Codex账号。

**微信（可选）**需要PushPlus账号及平台要求的实名/扫码。开发设置里的开放接口、安全IP和新密钥由本人在平台页面完成；这些账号设置没有在本项目里用浏览器会话自动代填。向导会给入口、显示当前出口IP并继续核验，之后自动处理固定入口和连接。

如果网络、企业策略、系统权限或平台人机验证阻止下载/登录，需要你处理该外部限制；脚本不会关闭证书校验、白名单或系统防护来绕过。

## Python备用安装

没有winget，或winget安装失败时：

1. 打开[Python官方Windows下载页](https://www.python.org/downloads/windows/)。
2. 安装Python 3.13或更新的x64版本；采用普通用户安装即可。
3. 重新双击`一键部署.cmd`。

也可以指定已安装解释器：先在终端设置`LITERATURE_PYTHON`为该`python.exe`完整路径，再运行`deploy.cmd`。

## 后续启动和停止

`start.cmd`打开正式实例；`stop.cmd`请求安全停止，只处理本应用管理的实例，不按进程名称批量杀Python或Node。

如果正在生成长篇精读，停止会先等待结果收尾。等待超时会明确报告，保留数据，不强制杀进程或继续覆盖构建。需要更长等待可用：

```powershell
.\deploy.cmd stop --wait 900
```

演示实例独立管理：`deploy.cmd stop --demo`、`deploy.cmd start --demo`。

## 更新

双击`update.cmd`。它会先安全停止本实例，下载固定到GitHub提交的源码，重新执行新版安装程序，再保留原数据目录继续运行。不会把数据库、凭据复制到GitHub。

更新需要网络。源码文件是应用管理的，手工改过代码的开发者应先提交自己的修改，采用Git合并；不要使用面向普通使用者的覆盖式更新。不要在同一份源码里同时维护演示与正式实例并并发更新。

移动了源码目录时，重新运行`deploy.cmd`登记新路径；需要登录启动时再运行一次`deploy.cmd autostart`。

## 可选设置

```powershell
# 修改兴趣与学习基础
.\deploy.cmd profile
# Windows登录后静默启动
.\deploy.cmd autostart
# 取消登录启动
.\deploy.cmd no-autostart
# 查看运行状态
.\deploy.cmd doctor
```

时钟由本机进程执行，电脑必须开机联网。关闭浏览器不停止后台服务；关闭电脑后不会由GitHub代跑。
