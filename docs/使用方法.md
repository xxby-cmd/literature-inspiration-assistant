# 阅读与研究

## 每天一小时

先浏览五篇大白话简介，再挑一两篇粗读；有价值的再精读或实践。每日固定三篇兴趣、两篇拓展，不把探索项替换成兴趣的改名版本。08:30开始准备日报和五篇基础粗读，09:00/21:00提醒同一组。

精读、翻译、再通俗一点和实践是新的模型任务，需要等待，也使用自己的Codex额度。准备失败会显示可重试，不会为了凑五篇而编造论文或反复消耗额度。

## 阅读器

顶部四个档位：简介、粗读、精读、中文翻译。切换时不整页重载，各篇各层分别保存位置。返回列表仍在原来的位置；重开可以点“继续上次阅读”。网络断开时尽量先显示已缓存内容，但未缓存页面仍需要本机服务在线。

粗读后可以点通俗解释、精读、喜欢或无感；精读后可以实践、已读或通俗解释。继续“再通俗一点”会基于实际上一版内容降低难度。解释不能为了简单而改变论文结论或隐藏限制。

只有摘要或翻译许可不足时，“中文翻译”会明确成为摘要中文解读。助手管理的译文七天到期清除，非译文采用有界浏览器缓存；清理浏览器数据会丢失本机浏览器进度，但不会删除服务端研究历史。

## 从问题出发

点击“主题调研”，输入问题后提交。这里的新五篇以相关性为先，包含直接研究和有用的背景/方法；不要求为了跨领域而跑题。对于课题是否已有前人研究，结果只能说明实际检索覆盖和最接近研究，不能保证“全网无人做过”。

输入区一直位于主题页上方，下面是“查过的主题”，按查询时间倒序排列。切出、返回、刷新后历史仍在；“查看这次文献”打开原结果，不重新检索、不覆盖当天日报。

“再找5篇”和“找相似文献”也保存为独立历史分组。新结果不会改变旧组的论文编号、解释链和阅读标记。

## 书架与偏好

“稍后读”和“已读”互相独立，刷新后保留。“喜欢”影响以后的兴趣推荐，“无感”按中性处理；太难不等于不感兴趣，没点击也不当作负面反馈。每天两篇探索仍保留。

运行`deploy.cmd profile`可修改兴趣与基础。不会读取你的私人微信聊天来推断偏好。
