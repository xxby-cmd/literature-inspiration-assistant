# 文献启发助手

每天读五篇论文的简报，再决定深入哪一篇。用中文大白话解释研究问题，保留原文入口，支持粗读、精读、翻译、逐层通俗解释，以及从一个研究问题查找相关文献。

**下载源码后，双击 `一键部署.cmd`。** 自动准备依赖、构建网页、创建数据库和启动阅读器。你只需要完成自己的账号登录；微信是可选功能。

当前完整自动部署目标是 **Windows 10/11 x64**。macOS、Linux 和云服务器尚未完成整套验证，不能直接套用 Windows 的凭据与启动实现。

## 三步开始

1. 点击仓库右上角 **Code → Download ZIP**，解压到普通文件夹，不要直接在压缩包里运行。
2. 双击 **`一键部署.cmd`**。首次运行会检测 Python，必要时通过 Windows 包管理器安装；Node.js 不合适时下载经官方 SHA256 核验的便携版。随后自动安装锁定依赖、构建、建库。
3. 按提示在官方页面登录你自己的 **ChatGPT/Codex 账号**，填写关注方向。完成后自动打开本机阅读器。

已有 Git 的用户也可以：

```powershell
git clone https://github.com/xxby-cmd/literature-inspiration-assistant.git
cd literature-inspiration-assistant
.\deploy.cmd
```

**先体验、不登录：** 双击 `先体验.cmd`。演示数据会明确标注，不是真实论文，不调用模型。演示与正式使用的数据分开保存。

完整教程：[安装部署](docs/安装部署.md) · [微信接入](docs/微信接入.md) · [使用方法](docs/使用方法.md) · [常见问题](docs/常见问题.md)

## 可以做什么

- 每日五篇：三篇贴近兴趣、两篇跨领域探索；08:30 开始准备，09:00 和21:00提醒，晚上复用当天五篇。
- 五篇基础粗读提前生成，复用已有结果；精读、译文、进一步解释和实践按需生成。
- 阅读器内部切换简介、粗读、精读和中文翻译。返回保留位置，重开可继续；正文支持表格、公式和代码。
- 主动“再找5篇”、主题调研、相似文献；新结果作为独立历史分组保存，保留原有文献。
- 主题调研页：上方输入问题，下方按查询时间倒序展示历史；切换、刷新和查看历史不会重新调用模型。
- 稍后读、已读书架和明确兴趣反馈。
- 可选微信：ClawBot只接收简报与固定入口，详细内容在网页阅读，完成后不额外刷屏。

## 自动做什么，必须本人做什么

| 步骤 | 自动处理 | 需要本人协助 |
|---|---|---|
| 本机依赖、构建、数据库 | 检测/准备Python和Node、`npm ci`、构建、建库、检查就绪 | 缺少winget时按教程安装Python；网络拦截时恢复网络 |
| Codex | 安装官方CLI、隔离配置、打开官方登录、检查认证方式 | 登录自己的ChatGPT账号，完成必要的人机验证 |
| 微信（可选） | 加密保存凭据、核验接口、下载连接组件、创建并更新本人固定入口、发送经同意的测试 | PushPlus注册/登录、平台要求的实名、关注/扫码、开启开放接口、填写自己的token/SecretKey、确认手机可见 |
| 运行 | 启动本实例、自动选择空闲端口、内置时钟、恢复连接 | 电脑保持开机联网；ClawBot按平台规则主动对话 |

不需要 GitHub 账号才能下载使用，也不需要 Cloudflare 账号或 Codex 内部 Sites 项目。这里的“部署”是**在自己的 Windows 电脑上运行**；手机访问通过可选隧道转到这台电脑，并不等于部署成离线也在线的云服务。

## 费用与账号

真实检索和生成使用你自己的 ChatGPT 登录及可用 Codex 额度。打开已完成文章、返回、历史和书架不调用模型。提前生成粗读只是提前等待，仍消耗额度。

应用使用独立 `CODEX_HOME`，不会复制作者的账号或读取你的桌面Codex配置。会移除API密钥环境变量，拒绝API登录，不自动切换付费API、购买会员或续费。PushPlus的可用功能与限制以该账号和平台当前规则为准；默认流程不依赖付费表单回调。

## 日常入口

| 文件 | 用途 |
|---|---|
| `一键部署.cmd` / `deploy.cmd` | 首次安装，或重新检测和配置 |
| `start.cmd` | 启动已安装的正式实例 |
| `stop.cmd` | 安全停止本实例 |
| `update.cmd` | 从本仓库获取新源码、更新依赖并保留本机数据 |
| `wechat.cmd` | 可选微信接入 |
| `doctor.cmd` | 查看运行状态，不显示密钥 |
| `先体验.cmd` / `demo.cmd` | 启动独立演示实例 |

登录Windows后自动启动是可选项：`deploy.cmd autostart`；取消：`deploy.cmd no-autostart`。这是程序自己的时钟，不创建Codex提醒。

## 数据与源码

默认数据放在 `%LOCALAPPDATA%\LiteratureCompanion\data`；演示放 `demo-data`。数据库、凭据、Codex认证、研究输出和日志不在源码目录，不会随Git推送。微信凭据与阅读入口码使用Windows当前用户DPAPI加密；Codex登录信息由官方CLI在独立目录管理。

助手管理的译文七天到期清除，不写入长期浏览器缓存。非译文有界缓存，阅读进度单独保存。检索历史持久保存在本机数据库。

```text
companion/     文献生成、内置时钟、队列、微信与私人阅读网关
reader/        阅读页面、服务端排版、分组与书架接口
scripts/       安装、登录、启动、停止、更新、接入与验证
tests/         不调用真实模型或发送微信的回归检查
docs/          教程、使用、排错与开发说明
launch.py      统一入口
```

## 验证与限制

项目提供本机清洁数据目录的演示安装、停止重启、重复安装、端口冲突和实例隔离检查；CI运行Python/Node测试、类型检查、构建和演示启动。不需要CI账号密钥，也不在CI调用模型或微信。

公开打包时不会继承作者的文献、偏好、固定入口、账号或内部站点身份。新用户的手机收发必须由其本人确认；作者无法代替其他账号完成实名和扫码。免费临时隧道不提供可用性保证，固定入口只是让访问地址不随隧道重启而需要重新保存。[开发与验证](docs/开发与验证.md)列明实际覆盖及未覆盖部分。
